# JavaScript Weather App

Project 1 of my 30 JavaScript Projects Challenge.

A responsive weather application built using HTML, CSS, and Vanilla JavaScript that fetches real-time weather data from the OpenWeather API.

---

## Features

- Search weather by city name
- Enter key support
- Error handling for invalid city names
- Real-time temperature display
- Wind speed conversion (m/s to km/h)
- Humidity information
- Glassmorphism UI design
- Responsive layout

---

## Architecture Approach

The application uses asynchronous API requests and dynamic DOM manipulation to fetch and display real-time weather information.

- Users enter a city name to search for weather data
- The Fetch API retrieves weather information from OpenWeather
- `async/await` handles asynchronous API requests
- Error handling manages invalid city names and failed requests
- Weather information is dynamically displayed by updating the DOM
- Wind speed is converted from meters per second to kilometers per hour

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Fetch API
- OpenWeather API

---
