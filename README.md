# JavaScript Weather App

Project 1 of my 30 JavaScript Projects Challenge.

A responsive weather application built using HTML, CSS, and Vanilla JavaScript that fetches real-time weather data from the OpenWeather API.

---

## Features

- Search weather by city name
- Enter key support
- Error handling for invalid city names
- Real-time temperature display
- Wind speed conversion (m/s to km/h)
- Humidity information
- Glassmorphism UI design
- Responsive layout

---

## Tech Stack

- HTML5
- CSS3 (Gradients and Glassmorphism)
- Vanilla JavaScript
- Fetch API
- OpenWeather API

---

## What I Learned

- Using `async/await` with the Fetch API
- Handling API responses and errors properly
- Dynamically updating the DOM
- Improving UI with micro-interactions
- Structuring a clean frontend project
